# My Task Assistant

仕事とプライベートのタスクを一元管理する、個人用のタスク管理アプリです。
HTML / CSS / JavaScript だけで作っているので、インストール作業は不要です。

## できること（バージョン1）

- 「仕事」「プライベート」タブの切り替え
- 文章を入力して「追加」でタスク登録（開いているタブに登録されます）
- タスクをタップして編集（タスク名・カテゴリ・期限・優先順位・メモ）
- 左の丸をタップで完了チェック（数秒間「元に戻す」が使えます）
- 削除（編集画面の「削除」ボタン。こちらも「元に戻す」が使えます）
- 絞り込み：すべて／今日／今週／期限なし／完了済み
- 期限切れは赤、今日〜3日以内は橙、優先順位「高」は左端が赤い帯
- 並び順：期限が近い順 → 優先順位が高い順
- データはブラウザ（ローカルストレージ）に保存され、次回も残ります

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（色は先頭の `:root` で変更できます） |
| `js/storage.js` | データ保存の担当（将来クラウド保存に変えるときはここを差し替え） |
| `js/app.js` | 画面の動き |

## iPad での動作確認方法（GitHub Pages で公開）

1. GitHub でこのリポジトリを開き、「Settings」→ 左メニュー「Pages」を開く
2. 「Branch」で公開したいブランチ（例：`main`）と `/ (root)` を選び「Save」
3. 1〜2分待つと、同じ画面に `https://ユーザー名.github.io/department-task-manager/` のURLが表示されます
4. iPad の Safari でそのURLを開く
5. （おすすめ）共有ボタン →「ホーム画面に追加」で、アプリのように起動できます

> ※ 作業ブランチの内容を確認したい場合は、そのブランチを main に取り込む（Pull Request をマージする）か、
> Pages の設定でそのブランチを選んでください。

## 注意点

- データはそのブラウザの中だけに保存されます。iPad と iPhone の間では共有されません（将来の共有機能で対応予定）。
- Safari の「プライベートブラウズ」では、閉じるとデータが消えます。
- Safari の設定で「履歴とWebサイトデータを消去」するとタスクも消えます。
